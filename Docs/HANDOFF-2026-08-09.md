### 1. THE HOST DRUM OPTIONS — finish the audio table

`options-all-midi-options-1` and `-2`. `options.drum` is a space-separated string that
splits into the same array `%%MIDI drum` already produces, so `normalizeDrumDefinition`
needs nothing new. `drumIntro` is the count-in (`abc_midi_sequencer.js:510-537`): whole
measures of rests spliced onto the front of EVERY voice, with the pickup subtracted from the
last of them, and `drumOff` inserting a drum-off after. The expected events carry pitch and
volume as STRINGS — abcjs passes the host's tokens through unparsed.

### 2. `chordGrid` — a feature with a 24-case oracle already written

`visual/chord-grid.test.js`. Harvest it the way `midi.test.js` was harvested — evaluate the
file with `describe`/`it`/the assert helper stubbed; `scripts/harvest-abcjs-midi.mjs` is the
small pattern, and it checks a SENTINEL reached the assertion so it cannot harvest the wrong
side of a comparison. Largest single feature gap in the repo.

### 3. `setTiming` — the audio↔geometry join, unmeasured

`timing.test.js`, 16 cases. See the checkpoint's WHAT IS LEFT §3.

### 4. THE STRUCTURAL PASS — step 1 done, the rest queued

Split `layout.ts` along its seams; close the `ENGRAVE` bare-literal table; the module-level
mutables if they are a real hazard. **NO BASELINE MAY MOVE** — if one does, that is a
behaviour change; revert it rather than re-record it. And do not "clean up" the comments:
`layout.ts` is 49% comment and those comments ARE the finding ledger.

### 5. TWO THINGS THAT NEED LANCE, NOT CODE

- **The compat wiring.** `setUpAudio` and `getMidiFile` both have working answers; neither
  is on `src/index.ts`'s curated surface, and hanging them on the compat tune object makes
  them part of the drop-in contract. ARCHITECTURE.md governs.
- **Does `abcjsStrict` owe byte parity on the MIDI FILE?** v1's `MIDIWriter.swift` is
  clean-room from the MIDI 1.0 spec, not an abcjs port, so it will not reproduce abcjs's
  four quirks — and `abcMusicKitCpp`'s `smf.h` inherits that. abcts reproduces them. The
  answer should be the same across all three; it is in the sibling briefs as an open
  question.
