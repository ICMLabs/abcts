## WHAT IS LEFT, IN ORDER

### 1. FOUR ROWS, AND EACH IS NAMED

None of them is a search; all four are measured and the mechanism is written down.

- **`deline`, 2 rows: `%%maxStaves`.** An undrawn line's `staff.clef` has no `abselem`,
  which is what makes abcjs's `objEqual` differ and `deline` unshift a clef. It is an
  ENGRAVER mutation leaking into a DATA comparison, and reproducing it means crossing the
  parse/layout boundary this library keeps. **`Layout.engraved` now exists** — every system
  that was laid out, including the ones `%%maxStaves` stops drawing — which is the input such
  a fix would need.
- **`deline`, 2 rows: `frere-jacques`'s prose spans.**
- **`Editor`, 2 steps.** `visual-selection-03` at `staffwidth: 300` writes its `treble+8`
  octave marker at `M 306.8125` where abcjs writes `306.81250000000006`: ONE ULP, repeated

### 2. OUR `parseOnly` ENGRAVES AND abcjs's DOES NOT

abcjs's `parseOnly` is `renderEngine` with a callback that does nothing, so its pitches carry
no `highestVert`, no `averagepitch` and no `printer_shift`. Ours is `renderAbc(['*'])`, which
lays the tune out — **two thousand rows of the `sequence` harvest were nothing but that
difference** before the oracle was moved onto a rendered tune. No gate here can see it,
because every oracle is harvested from a rendered tune; a HOST calling `parseOnly` gets
fields abcjs does not give it. Closing it means making the engrave-time stamping conditional
on a render, which is a decision about the projection's laziness, not a bug fix.

## THE TRAPS THIS SESSION PAID FOR

### ⚠️ A PROBE MUST USE THE HARVESTER'S OWN PARAMS

The page-walk hunt's first run compared `{staffwidth: 670}` against a golden harvested at
`{}`, printed four systems whose tops matched OURS exactly, and read as *"there is no defect
at all"*. `renderAbc` passes abcjs's own 740 default; `layout(score, {})` does not.

### ⚠️ AN ARRAY IS AN IDENTITY

`stavesHere` recovers a staff with `voicesOfStaff.indexOf(members)`. Filtering that list into
a NEW array cost eleven byte-exact fixtures their brace — every one a tune with no `&` in it.
Filter a COPY inside the consumer instead.

### ⚠️ A CACHE GUARD MUST MATCH ITS SENTINEL

`if (selectableCache === undefined)` on a cache initialised to `null` skipped the whole
build, silently emptied `tune.lines`, and took eight tests red in one run.

### ⚠️ AN EMPTY PART IS NOT A FREE ONE

Dropping a silent overlay layer from the staff MERGE left it in the line SOLVE, where a voice
with no staff-extra still moved the left edge by five pixels.

### ⚠️ MEASURE BOTH WAYS BEFORE WRITING THE RULE

Which clef a key is pitched for needed `parse-tie-slur-04` AND `visual-layout-07` pulling
opposite ways; either alone writes the wrong rule. `getMinWidth` over EVERY glyph looked
right on the one row it fixed and put 169 others out.

### ⚠️ AND THE ORACLE'S ENTRY POINT IS PART OF THE EXPERIMENT

`parseOnly` and `renderAbc(['*'])` are the same tune and NOT the same object — see §2.
