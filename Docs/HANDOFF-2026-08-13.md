## 4. THE RULES THIS ARC EARNED

- **PRINT THE SAME QUANTITY FROM BOTH ENGINES IN ONE SITTING.** A source read gives a
  hypothesis; the pair of numbers gives the answer. Five careful chains of source reads on
  this branch have predicted something abcjs's own output denies.
- **A PROBE THAT PRINTS THE RIGHT ANSWER HAS RULED SOMETHING OUT** — worth as much as one
  that prints the wrong one. That is how the multi-staff group rule was found.
- **SILENCE IS A SHARPER SIGNAL THAN A WRONG NUMBER.** A probe that prints abcjs's answer
  and nothing from ours moves the search from "our arithmetic is off" to "this code never
  runs".
- **CHECK WHERE THE PROBE SITS.** `beambr`'s `+= elem.w` guard was written down as
  provably not firing; the probe was printing the value AFTER the adjustment.
- **A HALF-UNDERSTOOD FIX IS WORTH LESS THAN A WRITTEN-DOWN MEASUREMENT.** Four things were
  reverted this arc and every one left its numbers at the site.
- **A ULP IN AN x IS A WALL, NOT A HUNDREDTH.** The clef octave marker's last bit sat at
  byte 6931 of 85865 on two fixtures; closing it took both to 51404.
- **A CONSTRUCTED OFFSET IS BUILT, NEVER DERIVED** — `(x + a) - x` is not `a`. When a byte
  row is a pure ULP in an x, ask FIRST whether the offset is recovered as `g.x - el.x`.
- **A ROUNDING-SIZED CONSTANT INSIDE A COMPARISON IS NOT A ROUNDING-SIZED ERROR.** The
  tuplet's 0.0098 of a pitch decided whether a bracket was flat or sloped.
- **READ THE BASELINE DIFF'S SHAPE**: a new feature only ADDS, a reorder is a pure
  PERMUTATION, REMOVALS mean something broke.
- **A GATE'S REPORT FILE IS NOT ITS RESULT.** `/tmp/abcts-*.txt` outlives the run.
- Never `push --force`, never `pull --rebase` unattended; if a push is rejected as
  non-fast-forward, STOP and report it. Omit `Co-Authored-By` trailers in this workspace.
