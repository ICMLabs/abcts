## ⭐ THE METHOD

**⭐ ENUMERATE THE REFERENCE, NOT YOUR OWN TYPE.** `grep -oE "params\.[a-zA-Z_]+"` over
`write/engraver-controller.js` says abcjs reads TWENTY-TWO host options. `AbcjsParams`
declared twelve. The ten missing ones became ten `zzopts` rows and **nine of them opened**.
The same rule found sixteen directives in one sweep in August.

**⭐ AND A BETTER WITNESS FOR AN OPTION ROW THAN A REGEX: DOES THE OPTION MOVE abcjs AT
ALL?** A row whose option changes nothing in abcjs's own output on any fixture now reports
MUTE, because the comparison then proves only that two engines both ignored it. A regex
witness is hard to write for `minPadding` and easy to get wrong; this needs no judgement.

**⚠️ AND THE SAMPLE CALLED THREE ROWS MUTE THAT ARE NOT.** `germanAlphabet`, `accentAbove`
and `expandToWidest` all read MUTE on a 1-in-12 walk and are 10, 13 and 14 over the whole
corpus. **A sample is a lower bound for the WITNESS as well as for the count** — which is
the older trap arriving from a new direction.

## 🔬 WHAT LANDED

**`style=` IS A VOICE-LINE PROPERTY, NOT A VOICE ONE.** The `ponytail:` marker predicted a
model change rather than a patch and **the size was right**. Three rules, ten rungs:
`K: style=` is GLOBAL (`multilineVars.style`) where it was read as the current voice's; a
voice-line's style is fixed WHEN THE LINE OPENS and a `V:` FIELD opens one — the whole
difference between a single-voice tune, where a leading `[K: style=]` does reach its own
line, and a multi-voice one, where it does not; and a line with no style of its own INHERITS
the last one engraved, because `pushCrossLineElems` saves the slurs, ties, endings, colour
and scale and not `this.style`.

**`voiceScale` IS ONE TOO** — a `scale` ELEMENT re-asserted at every line head. ⚠️ **But the
directive reaches the line it stands in, where a `[K: style=]` does not**: `%%voicescale`
appends an element immediately AND sets the running value, and the style has only the
second. Collapsing the two left a rung failing each way round.

**THE PRINT/SCALE ROUND TRIP — EIGHT GATE ROWS IN ONE EXPRESSION.** `setPaperSize`
multiplies `w` by the scale and hands `setSize` `w / scale`; the emitter wrote `wRaw` with a
comment saying the two cancel. **`(x * 0.75) / 0.75` is not `x`.** print 7 → 5,
`scale 0.8` 4 → 1, `oneSvgPerLine + scale 0.8` 4 → 1.

**`ariaLabel` AND `germanAlphabet`.** The first was 685 of 685 — we always wrote the default
label — and has three states, the middle one being the surprise: a STRING replaces only the
attribute, `''` emits neither the attribute nor the `<title>`.

## ⚠️ WHAT IS OPEN — the seven host options, and they are ordered by size

Each is DECLARED in `zzopts` at its measured count, and each is a real feature rather than
a rounding difference: the count is how many fixtures a host passing it would see drawn
differently from abcjs.

1. **`timeBasedLayout` — 669.** A SECOND layout algorithm, `write/layout/layout-in-grid.js`,
   which spaces by TIME rather than by the spring solve. The largest single item anywhere in
   this repo now.
2. **`lineThickness` — 665.** An ADDITIVE term on four line widths, and the mapping is not
   uniform: `dy + lineThickness` on a staff line and a ledger are HALF-thicknesses
   (`draw/staff.js:14`, `:25`, `draw/relative.js:66`), while `linewidth + lineThickness` on a
   bar and `linewidth ± lineThickness` on a stem are WHOLE ones, the sign following the
   stem's direction (`draw/relative.js:61-63`). `ABCJS_LINE_PX` already documents the term
   it does not carry.
3. **`minPadding` — 659.** Extra room to the left of every note and bar in the solve —
   `getExtraWidth` adds it for a `note` or a `bar` only, and `layoutOneItem` skips it for
   anything still fixed to the left edge (`layout/voice-elements.js:34`, `:110-115`).
4. **`initialClef` — 125.** Reprints the clef at the head of the tune.
5. **`wrap` + `staffwidth` — 60.** Re-lining IS implemented (`compat/wrap.ts`, gated on its
   own numbers) and **no gate had ever compared its rendered OUTPUT to abcjs's**.
6. **`add_classes` — 17.** The class scheme is gated by 111 sibling goldens; these are the
   rows those goldens do not reach.
7. **`expandToWidest` — 14.** A line too stiff for the page widens the PAGE to fit it.
8. **`accentAbove` — 13.** An `accent` joins the ABOVE stack instead of the below one
   (`creation/decoration.js:20`), which moves every lane with it.

## TRAPS

- ⚠️ **A SAMPLE IS A LOWER BOUND FOR THE WITNESS TOO**, not only for the count.
- ⚠️ **A DELIBERATE BREAK CAN MISS THE CODE IT WAS AIMED AT.** If a break changes nothing,
  suspect the PROBE. `zzclick`'s whole coordinate path was untested minutes after it went
  green.
- ⚠️ **AN ALGEBRAIC IDENTITY IS NOT A FLOATING-POINT ONE** — `(x*s)/s`, `x*STEP/STEP`,
  `(w-2m)+2m`. Three now.
- ⚠️ **A `getBBox` CANNOT SEE A GLYPH'S SCALE.** A scaled glyph is CSS-scaled and its path is
  untouched, so five rungs agreed at 9.81px and measured nothing. The fact was already in
  `CLAUDE.md`; `getBoundingClientRect` is what sees it.
- ⚠️ **A SHARED FIRST-THREE IS NOT A SHARED SET.** Twice: on `zzopts`, and on `zzclick`,
  where two fixtures looked alike and had different causes.
- ⚠️ `selectable="false"` is a TRUTHY string. A repo test can assert the defect. A gate can
  normalise it away. A floor rots. The suite times out under load and it is not a defect.
