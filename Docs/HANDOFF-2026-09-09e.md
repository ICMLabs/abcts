## ⭐ THE METHOD — what these six had in common

**⭐ EVERY ONE WAS A NAMED `if` IN abcjs, AND THREE OF THE SIX DID NOT MEAN WHAT THEY SAY.**

- **`initialClef` MEANS THE INITIAL CLEF *ONLY*.** `(!this.initialClef || l === 0) &&
  createClef(…)` with `l` the LINE index — it SUPPRESSES the clef on every system after the
  first. The name reads as though it adds one, and a six-rung ladder is what settled it.
- **`lineThickness` IS NOT THE SAME SIZE AT ITS FIVE SITES.** `printLine`'s width argument
  is a HALF and `printStem`'s is WHOLE, so a staff line and a ledger gain **2 ×** the term
  and a barline and a stem gain **one**. And the stem's `linewidth > 0 ? +t : -t` is a
  SIGN, not a size — the magnitude grows either way.
- **`minPadding` IS PART OF WHAT THE ELEMENT WANTS, NOT A GAP ADDED AFTER.**
  `getExtraWidth(child, pad)` returns `-child.extraw + pad` and the same SHORTFALL test
  spends it, so an element with slack in front of it costs nothing. Adding it to the cursor
  would have widened every line by the full amount.

**⭐ AND THE GLYPH IS THE DISCRIMINATOR THAT CANNOT GO STALE.** `accentAbove` keys on
`articAccentAbove` rather than on the name `accent`, because abcjs canonicalises `>`, `<`
and `emphasis` in the PARSER and we keep the source spelling — so all four spellings got the
rule for free. The same choice the accent's y already made in August.

**⚠️ AND A CHANGE THAT MOVES NOTHING MEANS THE OUTPUT IS NOT READING THAT INPUT.** The
obvious `add_classes` fix — make the group opener fall back to the `startGroup` row's
`klass` — changed **nothing**, so those groups are opened somewhere else. Reverted rather
than kept: unproven code that does nothing is worse than an open row.

## TRAPS

- ⚠️ **AN OPTION'S NAME IS NOT ITS BEHAVIOUR.** Ladder it. `initialClef` suppresses.
- ⚠️ **A WIDTH ARGUMENT MAY BE A HALF OR A WHOLE.** `printLine` and `printStem` disagree,
  and the same constant lands at two sizes.
- ⚠️ **A CHANGE THAT MOVES NOTHING MEANS THE WRONG INPUT** — revert it and find the site.
- ⚠️ **A SAMPLE IS A LOWER BOUND FOR THE WITNESS AS WELL AS THE COUNT.**
- ⚠️ A `getBBox` cannot see a glyph's SCALE. A deliberate break can miss the code it was
  aimed at. An algebraic identity is not a floating-point one. A shared first-three is not a
  shared set. `selectable="false"` is truthy. A floor rots. The suite times out under load.
