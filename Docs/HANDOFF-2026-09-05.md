## ⭐⭐ THE PATTERN THAT PRODUCED NINE OF THIS SESSION'S FIXES

**A RULE PORTED AT THE SITE THAT NAMED IT IS NOT A RULE PORTED.** Nine times this session
the rule was already understood, cited and implemented SOMEWHERE in this repo, and simply
not carried to the site being fixed:

| the rule | where it already was | where it was missing |
|---|---|---|
| the meter is the STAFF's, not the header's | `chord-grid.ts`, in a comment | the MIDI writer |
| `millisecondsPerMeasure` over a Score | `timing.ts`, exported | the compound-meter tempo |
| the track name is `staff.title.join(" ")` | `compat/lines.ts`, in a comment | the flattener |
| a mid-tune `clef=perc` moves the drummap | `compat/lines.ts`, with the citation | the flattener |
| `%%staffnonote 0` drops a soundless staff | `layout.ts`, with `sounds()` | the audio tracks |
| `renderEngine` is one tune per SLOT | `renderAbc`, fixed 2026-08-15 | `getMidiFile` |
| the slur count moves INSIDE the pitch loop | the comment AT THAT SITE | the code below it |

**So the second step is not optional.** `grep -rn "<the rule>" src/` before writing it.

## ⛔ MEASURED, INSTRUMENTED AND DELIBERATELY NOT LANDED

Both are in `ABCJS-DEBT.md` with both engines' numbers. **Do not re-derive them; read them.**

1. **The sequencer resets `currentVolume` per LINE-VOICE** (§3b.5).
   `currentVolume = [105, 95, 85, 1]` sits immediately before
   `for (var v = 0; v < voice.length; v++)` (`abc_midi_sequencer.js:223-225`), and that loop
   runs once per (line, staff, voice). Instrumented output is in the entry. **Two ports were
   written and BOTH reverted**: resetting only under an open hairpin made all four ladder
   rungs exact and took two byte-exact fixtures to differing; resetting unconditionally took
   the gate 27 → 31. The ladder passing while the corpus regresses says the rule interacts
   with the FLATTENER's carry — a different variable in a different file — in a way neither
   cut models. Open row: `abcts-ledger-gaps-4#1`.
2. **`(p:q:r` with `r = 1` never clears `tripletMultiplier`**, so every later note of the
   voice keeps two thirds (`abc_midi_sequencer.js:253-277`). Reproducing it means moving
   tuplet resolution from PARSE time to SEQUENCE time — a relocation, not a MIDI fix. Open
   row: `abcts-ledger-gaps#1`. The `r != p` TOTAL is ported and exact.
