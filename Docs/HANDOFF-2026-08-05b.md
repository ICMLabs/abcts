## WHERE TO START

### 1. THE `ENGRAVE` TRIAGE — 61 constants, and it is an audit rather than a hunt

`CHECKPOINT-2026-08-05b.md`'s second section has the census and the reasoning. The list of
49 bare literals is one `grep` away:

```bash
cd /Users/lrettberg/ICMLabs/Code/abcts
python3 - <<'PY'
import re
s=open('src/renderer/layout.ts').read()
body=re.search(r'const ENGRAVE = \{(.*?)\n\}', s, re.S).group(1)
for m in re.finditer(r'^\s{2}([a-zA-Z][a-zA-Z0-9]*):\s*(.+?),\s*$', body, re.M):
    if not re.search(r'ABCJS_|spaces\(|steps\(|spacesOfPitch\(', m.group(2)):
        print(f'{m.group(1):24} = {m.group(2)}')
PY
```

Three buckets. STRUCTURAL is fine (`spacePerStep` is a unit, `staffLineSteps` is the staff).
ABCJS-HAS-ITS-OWN gets ported and cited, and `stemLength` is the worked example — 3.5 spaces
is 7 pitch is `Math.round(70 * voiceScale) / 10`, the same number with no citation, so
nothing would catch it drifting. OURS BY POLICY must stop being readable from strict at all.

**The proof of an honest constants move is a re-recorded baseline diff of ZERO lines.**
`beamSpacing` was exactly that on 2026-08-05: Bravura's `0.5 + 0.25` staff spaces is 1.5
pitch precisely, so the value never moved and only its provenance did.

### 2. THE SLUR/TIE ENDPOINTS — and the quantity that is computed twice

Finding 89 ported `drawArc`'s SHAPE and deliberately left the endpoints. abcjs starts at
`anchor.x + 6`, ends at `+ 4`, and lifts both by `1.2` pitch for a tie or `1.5` for a slur
(`draw/tie.js:60-64`). Ours uses the anchor's ink edge and `curveEndGap`.

Before writing anything, read `curveReserves` in `layout.ts`: it ALREADY ports `calcSlurY`,
including the `parent.fixed.b` branch for an end anchored inside a beam. So abcjs's
`startY`/`endY` are derived there for the RESERVE and derived again, differently, in
`buildCurve` for the DRAWING. **The same quantity computed in two places whose inputs have
drifted apart is exactly the lyric-reserve bug**, and the fix is to have one of them.

## WHAT NOT TO CHASE

- **An arithmetic order-of-operations difference.** Measured and ruled out — finding 69.
- **The staff line's residual 0.002px.** That is abcjs's own `roundNumber` quantisation;
  our value is the exact one — finding 70.
- **A chord symbol with two bars.** Isolated on a control pair on 2026-08-05 and it was
  the `M:C|` METER all along (finding 86). It is closed; the rung that looked like it was
  a red herring.
- **`mouse-click-01`'s residual at two bars.** It reproduces only once the full line is
  JUSTIFIED — a two-bar cut of the same voices is exact — so it is a small width difference
  amplified by the justifier, not a spacing rule.
