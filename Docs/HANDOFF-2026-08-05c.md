## WHERE TO START

### 1. THE ENDING LANE — DONE, and kept because the SHAPE is the reusable part

abcjs's order above the staff (`set-upper-and-lower-elements.js:32-49`):

```
lyricHeightAbove
chordHeightAbove
endingHeightAbove   <- staff.top += (chordHeightAbove ? 2 : endingHeightAbove + margin)
                       positionY.endingHeightAbove = staff.top
                       ...and it is DRAWN at `positionY - 2` (:201), NOT at that top —
                       the only lane in the file whose reserve and draw points differ
dynamic / volume
partHeightAbove
tempoHeightAbove
```

Every constant in that chain already existed: `ENGRAVE.voltaLane` is `endingHeightAbove`,
`endingOverChordLane` the flat 2, `laneMargin` the 1. What was missing is that the bracket
was DRAWN at `stepToY(ENGRAVE.voltaStep)` in the per-voice packing pass, which runs long
before the stack. `anchorVoltas` is the post-pass shift, and it is the model for the lanes
still to migrate:

  • it reads the top FROM `verticalExtent` rather than re-deriving it, so the lane is
    spent in exactly one place;
  • it shifts FURNITURE ONLY, and the proof is a baseline diff that touches volta lines and
    volta texts and nothing else;
  • it is safe precisely because a volta's ink is outside the staff's extent by design —
    check that property before copying the pattern to a lane where it does not hold.
