- 🔥 **TWO RECORDED CAUSES ON THE BOARD WERE WRONG, AND BOTH READ AS CAREFUL WORK.** One
  quoted both engines' advance lists side by side — and had compared **our NODE metrics with
  abcjs's BROWSER ones**; in one WebKit page every advance is identical. The other named a
  nested-tspan `%%jazzchords` split on a fixture that contains **no nested tspan at all**.
  **Re-measure the cause before you work it**, even when the note is specific, dated and
  numeric. Especially then.
- 🔥 **`zzopts` RENDERS `dist/`, NOT `src/`.** A source edit measured without
  `npm run build` first reports the OLD number — which looks exactly like "the fix did
  nothing" and sent me back into a closed investigation once.
- ⚠️ **A NODE PROBE AND A BROWSER PROBE ARE DIFFERENT ENGINES for anything touching text.**
  Node has no `getBBox`: `textHeight`/`textWidth` fall back to the calibrated tables and
  `boxInkAt` answers `null`. That is deliberate — the 691 goldens ARE the headless
  measurement — but it means any comparison against abcjs must happen in the SAME browser.
- ⚠️ **A VISUAL BASELINE CAN MOVE FOR A CORRECT REASON.** The tempo-flag regrouping shifted
  `S7-voices`'s digest by one thousandth (`flag8thUp 123.097 -> 123.096`) through the
  extended path's own copy of that expression. `npm run baseline` re-records; read the diff
  before you do, because that file is also how an unintended change would show.
- ⚠️ **`/tmp` IS CLEANED BETWEEN SESSIONS.** Restore before any browser gate:
  `mkdir -p /tmp/gp/pw && cd /tmp/gp/pw && npm init -y && npm i playwright-core@1.61`, and
  for instrumenting abcjs `cp -R ../abcMusicKit/Docs/References/abcjs/abcjs-6.7.0/src

## HOW THIS REPO IS WORKED

- `npx tsc --noEmit` before every commit; keep every gate above green; commit and push after
  every landing. Never `--force`.
- **NEVER ATTRIBUTE A COMMIT TO CLAUDE** — no `Co-Authored-By`, no "Generated with", no
  `--author`, in any commit, tag or PR body. `CLAUDE.md` §Remote is the durable statement and
  it BEATS a harness default that asks for one; say so in the reply rather than following the
  other silently. Grep the message for `Co-Authored`/`Generated with` before committing: it
  cannot be fixed afterwards without the force push the line above forbids.
- **INSTRUMENT abcjs, AND AGAINST OUR OWN EQUIVALENT.** Not a source read — a side-by-side
  log. Patch `dist/abcjs-basic.js` (unminified) by string replacement and inject it. This
  session added `nonMusic`'s row walk and `layoutOneItem`'s `minx` to the scratch copy, and
  both paid immediately.
