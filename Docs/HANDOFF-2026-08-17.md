## WHAT TO DO NEXT, IN ORDER

### 1. `deline` — and the point is that the ground under it moved TODAY

**`deline` MERGES MUSIC LINES AND MOVES STAFF-LEVEL METER/KEY/CLEF INTO THE VOICE STREAM**,
reading `staff.meter/key/clef` off the projected lines. It was recorded as blocked because we
did not project those — and §3 of the checkpoint changed exactly that: a standalone `K:` now
lands in a voice stream, a clef is its own element, and a `K:` naming a clef appends both,
clef first.

**RE-READ IT BEFORE ASSUMING IT IS STILL BLOCKED.** That is the same mistake the "unbuilt,
not a tolerance" note made about `-print` for a day, and the same one `metaText` made for a
week — a note that says why something is hard is the reason nobody re-reads it.

Build the oracle first, as every closed arc here did: `tune.deline()` over both corpora,
harvested by RUNNING abcjs. It is a PARSE product, so `/tmp/gp/mti.js` is the template rather
than `/tmp/gp/toptext.js`.

### 2. The five open `tune.lines` tunes — 43 characters, five separate mechanisms

Named with their character counts in `CHECKPOINT-2026-08-17.md` §5.1 and printed by
`npx tsx scripts/zzlines.ts`. Two are the same shape and worth doing together:

- **A PARSE FAILURE OWNS NO CHARACTERS.** `^3/2G` (a microtone strict cannot read) and a bare
  `#` both make `getCoreNote` return null, and abcjs answers NULL for those characters while
  our note swallows them. 6 characters across two tunes.
- **AN OPENING `(` BEFORE A DECORATION BELONGS TO NOTHING, AND A `(3` DOES NOT.** `(vf/` has
  abcjs's note at the `v`; `(3B2` keeps its `(3` INSIDE the span.
  `letter_to_open_slurs_and_triplets` consumes the `(` run before `startI` is taken, and the
  triplet is the exception — **MEASURE WHICH before porting**, because the two look alike and
  that is how the `extra-class` accent and the `G8` breve each survived a week.
- **THREE `[M:]` IN ONE BAR AND ONLY THE LAST HAS A RANGE.** `Measure.meterChanges` carries
  `{meter, at}` with no source range, so the earlier ones are absent from the stream. The
  renderer already draws all three; this is a range per entry.
- **A standalone `K:D` abcjs answers NULL for**, where the same shape elsewhere is answered.
  Probe `/tmp/gp/lines.js` on `courtesy-key-before-subtitle` BEFORE touching the hoist: the
  rule is one of `appendStartingElement`'s three arms, and the "same type → REPLACE" arm has
  never fired here, so it may be that one.
