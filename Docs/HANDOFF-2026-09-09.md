## ⭐ THE METHOD, AND THE THREE THINGS ADDED TO IT

The standing order held again — **every one of these came from reading a named abcjs
function or probing its real output, and not one from a diff.** Three additions:

**⭐ A WITNESS ON EVERY CONTROL.** A control that agrees because the FEATURE NEVER RENDERED
is a held prediction that measures nothing. Each row now carries a regex the shape must
produce in abcjs's own output, and a row that agrees without it reports **MUTE**. It fired
four times in eighteen — twice on my own witness (a hairpin's element is
`data-name="dynamics"`, and a notehead's `data-name` is its PITCH, not its glyph).

**⭐ A NEGATIVE CONTROL IN EVERY NEW HARNESS.** The MIDI sweep's control was a plain
four-note tune, and it DIFFERED on the first run: `getMidiFile` on a tune object returns a
STRING in abcjs and returned `[string]` here. **The gate that exists to prove that entry
point had normalised it away** — `Array.isArray(r) ? r[0] : r`, written to make the gate
work rather than to state the contract.

**⭐ AND A FLOOR ROTS.** Seven ratchets say "at least the rows it did". All seven are at
100% and six floors were slack by 48 to 844 rows. Proven it matters: adding 1 to `top` in
`timing.ts` took 180 of 180 cases red on the row COUNT while both of that file's other
assertions stayed green. They all read `agree === total` now.

## ⭐⭐ THE PATTERN THAT NAMED FOUR OF THE FOUR: THE MARKER'S CAUSE WAS RIGHT, ITS SIZE WRONG

Every one of the ledger's four was written up as bigger than it was, and **two were symptoms

## 🔬 WHAT LANDED — seventeen, grouped

**LYRICS.** A melisma belongs to the verse that holds it. A `|` hint waits for the next
BARLINE and every element it waits through takes an EMPTY syllable — and `s:` lines take
the same walk, because abcjs's `addSymbols` is a copy of `addWords` **and differs in one
line**: its skip branch pushes no empty syllable, so a `*` in an `s:` line leaves its note
with no lyric where a `*` in a `w:` line leaves `&nbsp;`.

**TIES — the biggest single arc.** abcjs has TWO tie mechanisms and they are told apart by
WHERE THE `-` IS WRITTEN, never by how many heads carry one. Inside the bracket is
`inTieChord[<position>]`, read only by the next CHORD however far away; after it is
`isInTie`, consumed by the very next element, a REST included. Sixteen shapes byte-compared;
the audio and the drawing both landed, and the drawing carried a third rule — **a tie
nothing closes runs to `lineEndX`; there is no arm that drops it.** It fixed `S7-voices`
tune 6, which drew ONE tie where abcjs draws THREE.

**DIRECTIVES.** `%%voicecolor` reads `multilineVars.currentVoice`, which only a `V:` FIELD
sets — no `V:`, no colour, which is most tunes. `%%voicescale` was unimplemented and warned.
A mid-tune `%%newpage` costs nothing where a header one costs 61.33px, and its line stands
where it is written.

**THE COMPAT SURFACE.** `getMidiFile` on a tune object returns a string. And the whole
SELECTABLE markup — five defects, four of them invisible to the array
`tests/selection.test.ts` compares.

**JAZZCHORDS — 95 of 685 to zero.** The host param was ignored outright (only the DIRECTIVE
reached the renderer), and then two measurements read the FLAT chord string where abcjs
measures the DRAWN jazz form: the box round `G♭maj7` at 54px against 45, and the LANE
PACKING, which opened a second chord lane where abcjs fits one. **The rod had used the jazz
form all along — three sites, one rule, one of them had it.** `measuredText` answers it now.

**PRINT — `%%header` WAS PARSED AND NEVER DRAWN**, and print is the only mode that draws
one. Three rules with it: `headerfont`/`footerfont` are the ONLY two fonts print divides by
the scale (they sit outside the scaled drawing); the header RESERVES NOTHING, which abcjs
states in its own comment, though its rows still move the cursor; and its baseline is one
font size below the cursor like every other row. **And `%%topspace` never replaced the print
top row** — only print spends it, so nothing had rendered it.

**THE HOST OPTIONS.** abcjs SIZES THE CONTAINER — `overflow: hidden; height: <h>px`, plus
`width` below scale 1 — and we set nothing, on every render anyone has ever done here.
`responsive: "resize"` was unimplemented outright, and it **discards the scale**, in abcjs's
own comment: *"the resizing will mess with the scaling, so just don't do it explicitly"* —
the `%%scale` DIRECTIVE with it, not just the param. Two of the fixes were ORDERING rules,
because the browser serialises what we assign: the transform is re-applied after the four
position styles, and the `style` attribute is dropped so it is re-created after the
`viewBox`.

**GATE HYGIENE.** Seven ratchets tightened; the MIDI gate now asserts its return shape
rather than normalising it.

## TRAPS

- ⚠️ **A REPO TEST CAN ASSERT THE DEFECT.** FOUR did this session — the `s:` skip's empty
  syllable, `w:Do * | Mi Fa`, "still drops a curve with nowhere to land at all", and the
  `[C-E-]` collapse. Each was written from the same reading the defect came from, so it
  agreed with the code and with nothing else. **Probe abcjs before believing a red.**
- ⚠️ **A GATE CAN NORMALISE THE DEFECT AWAY** — `Array.isArray(r) ? r[0] : r`. If a gate
  needs a shim to compare, ask what the shim is hiding.
- ⚠️ **A SAMPLE IS A LOWER BOUND, NEVER A NUMBER TO DECLARE.** `jazzchords` was declared at
  13 from a 1-in-8 reconnaissance and is 95 over the whole corpus. The gate caught it on the
  first full run by reporting `UP`, which is what a declared count is for.
- ⚠️ **A FIXTURE WITH MORE THAN ONE OPEN CAUSE CANNOT RULE ANYTHING OUT** — the repo's own
  rule, and `visual-options-01-fonts` is the fixture it was written about. Ladder a CONTROL
  per variable instead: the header arc took four (no header, default font, a named font, a
  named font with a rejected `box`) and each one moved exactly one number.
- ⚠️ **HALF OF `setPaperSize` IS ON THE PARENT NODE.** A comparison of the SVG alone cannot
  see it — `zzopts` compares `outerHTML` for that reason, and every gate that came before it
  was blind to a container abcjs styles on every single render.
- ⚠️ **`git stash push` + rebuild + re-run is the way to tell a REGRESSION from a
  PRE-EXISTING difference**, and it was needed three times. Two of the diffs I found while
  fixing ties were older than the fix.
- ⚠️ **THE CHORD PITCH ORDER IS THE SOURCE'S UNTIL THE ENGRAVER SORTS IT** (`sortPitch`),
  and every flag travels with its own pitch object. `NoteAnchor.tieSrc` is that mapping.
