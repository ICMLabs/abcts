## THE THREE TRAPS THIS SESSION PAID FOR

### DO NOT RETAIN A `Layout` — IT KILLS THE SUITE'S WORKERS, AND IT READS LIKE A FLAKE

The selectables need the drawing, and the first cut kept it in each `TuneObject`'s closure.
A `Layout` is the biggest object this library makes and a host keeps every tune a render
returns: the full suite went from **5.6s to 50-120s and failed a DIFFERENT test on every
run** — pixel parity's ranked table, then a byte-exact sibling slug, then another. Nothing
about the failures said "memory"; they read as intermittent value differences. It is laid
out AGAIN inside the lazy accessor now (0.7ms, only when asked) and two consecutive full
runs are clean.

**And a rarer flake does exist underneath it** — one run in two failed `pixel-parity` with
the whole change stashed. Worth its own probe: different test each time across different
FILES is the shape of a worker dying, not of an assertion.

### THE GOLDEN GENERATOR'S FONT-HEIGHT TABLE HAS SEVEN ROWS

`dump-svg.js`'s `fontHeights` covers the seven sizes abcjs's DEFAULTS resolve to; anything
else falls through to `size + 2` where a browser gives about `size × 1.108`. **46 text
elements across both corpora set a size outside those seven.** Our engine reproduces the
fallback on purpose (`GOLDEN_TEXT_HEIGHTS`) so nothing is inconsistent here — but the
goldens and a browser part company on those rows, and that is now written down rather than
being a surprise the next time an oracle disagrees. `dump-svg.js` is in `../abcMusicKit`,
which another lane owns; do not edit it.

### A DISAGREEMENT WITH THE ORACLE IS EVIDENCE ABOUT THE HARNESS TOO

Nine of the eleven rows where abcjs's own suite disagrees with abcjs were OUR text metrics,
and the way to tell was to VARY the suspected input in a scratchpad copy and watch: the
obvious suspect — the `%%titlefont … 22.0` the tune actually sets — moved nothing at all,
and the real one (the 29px it resolves to) reproduced the test file's number to the digit.
**A fixture's own directive is not evidence, any more than its name is.**

### A RATCHET THAT NAMES ROWS CATCHES WHAT A COUNT CANNOT

The script that re-ratchets `tests/lines.test.ts` split the ranked report on whitespace,
which turned `sib/little swallow-tune0` into `sib/little` — a FAILING tune on the passing
list under a name nothing matches. The next run went red on it. The fix is in
`/tmp/relines.mjs`: strip the trailing ` n/m` instead of splitting.
