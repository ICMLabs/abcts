### 1. THE DRUM TRACK — 2 cases, and the algorithm is already written out

`flatten-drum`, `flatten-metronome`. `%%MIDI drum <pattern> <pitches…> <velocities…>` is
already parsed into `Score.midi.drum`; nothing reads it. The shape, from
`abc_midi_flattener.js:760-889` and set out in the checkpoint:

- the pattern string is `d`/`z` events with optional `/n` length suffixes;
- `params.pattern.length` must be exactly `totalPlay * 2 + 1` or the drums turn **off
  entirely** — abcjs is deliberately strict here and says so;
- pitches are `pattern[1 + i]`, velocities `pattern[1 + i + totalPlay]`;
- `alignDrumToMeter` scales every length so the pattern covers `drumBars` measures;
- `writeDrum(voices.length + 1)` runs on every BAR of **voice 0 only**, writes from
  `lastBarTime` — the measure that just ENDED — and returns early while
  `lastEventTime < measureLen`, which is how a pickup delays the first hit;
- a `drumChange` pushes its element to **voices[0]**, not the current voice.

### 2. `&` OVERLAY VOICES — 4 cases

`flatten-overlay`, `flatten-pickup-overlay`, `overlay-repeat`, `flatten-rep-and-over`.
`Measure.overlays` is parsed and rendered already; the sequencer has to append each layer as
its own voice, after the main line, the way abcjs promotes them.

### 3. NOTE MODIFICATIONS — 3 cases

`doModifiedNotes` (`abc_midi_flattener.js:425+`): `!trill!`, `!mordent!`, `!turn!`, `!roll!`,
`!pralltriller!`, `!trillh!` each become a RUN of `1/32` notes with `style: 'decoration'`,
alternating by a named interval, filling the note's duration. `findNoteModifications`
already resolves the names in `src/audio/flatten.ts`; only `doModifiedNotes` is missing.

### 4. MID-TUNE `%%MIDI` — 2 cases

`Measure.midiCommands` carries `gchord`, `gchordon/off`, `bassprog`, `chordprog`, `bassvol`,
`chordvol`, `drum`. The chord track already has a setter for each — `setGChord`,
`setBassProg`, `setChordProg`, `gChordOn` — and nothing calls them.
`flatten-change-gchord` and `cancel-gchord` are the cases.

### 5. THE TAIL

of single cases whose first differing event the table prints.

### 6. AFTER THE FLATTENER
