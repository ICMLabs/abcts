### 1. THE SVG, BYTE FOR BYTE — the arc

`npx vitest run tests/svg-bytes.test.ts && cat /tmp/abcts-svg-bytes-ranked.txt`

All 171 fixtures agree to byte ~153 — the whole root element. The first difference is one
attribute on every row: **the `viewBox`**. abcjs draws in ABSOLUTE PIXELS and writes none;
we draw in STAFF SPACES and let the viewBox convert, so it is the SYMPTOM and every
coordinate in the body differs too. **Removing it alone took 196 tests red in one run** —
`tests/pixel-geometry.ts` reads it to resolve our coordinates and every geometry gate is
built on that — so the change is: emit absolute pixels throughout, then the attribute and
the scaling go together, and the geometry gates start comparing like with like.

The other measured blockers are listed in `Docs/ABCJS-DIFFERENCES.md`: `<rect>` for lines
where abcjs writes `<path>`, the note group's child order, the top text coming first in
abcjs's body, and the per-glyph `data-name`.

### 2. THE DOM CONTRACT — the same arc from the markup side

**86 of 694 rows, from 0.** The wrappers, the class scheme, the `fill`-on-`<svg>` depth fix
and the `add_classes` gate are in; CHECKPOINT-2026-08-09b §8 has them all with their
citations. **What is next is named by the table itself**: the per-GLYPH `data-name` at
depth 2 — `clefs.G`, `accidentals.flat`, `dots.dot`, `rests.half`, a bare digit for a
time-signature figure, and the WRITTEN NOTE NAME (`C`, `c`, `C,`) on a notehead. `stem`,
`ledger` and `bar` are already emitted; the rest is a `SMUFL_TO_ABCJS` lookup plus the
written name carried onto the glyph the way `durationClass` and `abcjsPitches` now are.
Then `abcjs-meta-top` for the header block, which is `dom-title-composer`'s row 0. And
`svg-per-line.test.js`'s five cases are deliberately NOT in the corpus: they assert an
`<svg>` COUNT under `oneSvgPerLine` / `responsive`, which compat does not implement at all.

### 2. THE ONE OPEN ROW, AND THE TIMING JOIN'S GEOMETRY HALF

- **`el-four-endings`.** `|1,3 … :|2,4 …`: abcjs's own `repeats.js` leaves the final
  ending's `end` undefined so `duplicateSpan` emits nothing for it, giving a second pass
  with NO ending. Closing it means porting that deliberately — a decision, not a bug fix.
- **The GEOMETRY half of the timing join has no oracle at all.** `left`, `endX`, `top` and
  `height` are on every `noteTimings` row and abcjs's own `timing.test.js` asserts none of
  them. A control ladder against its rendered SVG is the only route — a gate to BUILD.

### 3. The dynamic glyphs — the last measured Bravura leak in strict

The ANCHOR is exact; only the outline is Bravura's. CLAUDE.md's audit ruling says any
Bravura input reachable in strict is a defect, and this one is now measured rather than
