## WHERE TO START

### 1. THE REMAINING SEVENTEEN FONT DIRECTIVES

`%%gchordfont` is DONE and is the pattern — parsed by `parseFontSpec`, stamped per EVENT as
`chordFont`, size converted `round(pt * 4/3)`, and its lane taking the height from
`goldenTextHeight`. The other seventeen are parsed nowhere.

abcjs's mechanism is ONE place: `getFontAndAttr.calc(type, klass)` reads
`abcTune.formatting[type]`, and every size in the engraver comes from it. The grammar is
`%%<type>font <family> <size> [box]`, so the model can grow a `fonts` record keyed by type
rather than a field per font.

**CHANGING vs GLOBAL is a real split** (`abc_parse_directive.js:1019-1037`): gchordfont,
partsfont, tripletfont, vocalfont, textfont, annotationfont, historyfont, infofont,
measurefont, repeatfont and wordsfont can change MID-TUNE and belong on the element;
composerfont, subtitlefont, tempofont, titlefont, voicefont, footerfont and headerfont are
tune-level. `barlabelfont`, `barnumberfont` and `barnumfont` are all aliases of measurefont.

A boxed font measures `height + padding * 4` with `padding = size * 0.1`, which
`%%partsbox` already proved.

`visual-options-01-fonts` is `oy` −133.9 with all eighteen plus `%%header`/`%%footer`; the
two `selection-test` fixtures are 69.9 each. Judge all of it on the VERTICAL axes — see the
third golden limitation.

### 2. The horizontal model is a faithful PORT; the divergences are numbers in it

`lineAt` reproduces `layoutStaffGroup` + `voice-elements.js` element for element. So a
horizontal divergence is almost never the loop — it is a `w`, an `extraw`, a `minspacing`
or a duration. Instrument `layoutOneItem` to print
`type / dur / w / extraw / minspacing / x` and compare item by item; three of this
session's four horizontal fixes came out of exactly that, one run each.

Do not "fix" our `spacingReference` — our units are abcjs's × √2 and our `spacingScale` its
30 ÷ √2. The solve uses the product, so both are consistent.

  `dx`) — chord-symbol and note widths, no directives involved.

## STILL NEEDING A DECISION, NOT A COMMIT

**The gate hides failures.** All eight per-fixture assertions live in one `it`, so the first
to fail ends it. Collecting all four axes before asserting is the honest fix and will show
more red before it shows less.

**Mid-tune free text is dropped.** A `%%begintext` between two music lines is not drawn:
abcjs's justification rule is per LINE, so marking it as trailing justifies the wrong one,
and placing it properly needs free text to be a LINE rather than a property of the tune.

**A grace note before a `y` spacer is dropped.** `Rest` has no `graceNotes` field and the
model says so deliberately. abcjs disagrees for a SPACER.
